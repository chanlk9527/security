# 第四部分导读：安全交付、运行与现代应用

追踪数据和软件的生命周期，以隔离、验证、检测与恢复支撑现代应用。

本部分包含第 20～25 章，共 6 章。

## 章节地图

- [第 20 章：数据副本、隐私与删除](20-数据副本隐私与删除.md)——追踪数据从收集到复制、共享、保留和删除的完整路径。（章节概要）
- [第 21 章：运行环境、隔离与配置安全](21-运行环境隔离与配置安全.md)——限制进程、网络和管理能力，缩小配置错误与组件失陷的影响。（章节概要）
- [第 22 章：依赖、构建与软件供应链](22-依赖构建与软件供应链.md)——从源码到线上制品，核对每一次变更和交付的来源。（章节概要）
- [第 23 章：安全验证与持续评审](23-安全验证与持续评审.md)——把安全要求转为可重复执行的测试、检查和评审。（章节概要）
- [第 24 章：检测、响应与可信恢复](24-检测响应与可信恢复.md)——发现异常、撤销能力、限制扩散，并恢复到经过验证的状态。（章节概要）
- [第 25 章：AI 与 Agent 的信任边界](25-AI与Agent的信任边界.md)——把身份、输入、授权和运行控制应用于检索与工具调用。（章节概要）

## 本部分的学习产出

- 一份标明用途、访问者和保留期限的数据流转清单。
- 一份运行权限、网络可达性和隔离边界基线。
- 一条从部署制品回溯源码和构建过程的证据链。
- 一份按风险组织的安全验证计划和发布证据。
- 一份经过演练的事件响应与恢复剧本。
- 一份 AI 助手的数据访问、工具执行和验证边界说明。

## 建议的阅读方式

沿着数据流转、环境部署、软件交付、验证、事件处置的顺序阅读。最后把前面各部分的身份、授权、输入与隔离机制应用于 AI 助手。每章都应形成可检查的配置、记录、测试或演练结果。

本部分以多租户协作与文件处理平台为主案例，局部场景用于说明单个机制。当前章节状态和后续扩写范围见[全书大纲与定位](../全书大纲与定位.md)。
